Дневник заметок и навык Алисы

Веб-приложение с ORM, авторизацией, файлами, REST API и вебхуком для Яндекс.Алисы: голосом можно слушать список заметок, диктовать новые и смотреть погоду.

Регистрация Вход

Веб

Bootstrap, SQLite, загрузка картинок к заметкам.

REST API

Bearer-токен в профиле, JSON для заметок.

Алиса

Endpoint POST /alice/webhook, привязка по коду с сайта.
